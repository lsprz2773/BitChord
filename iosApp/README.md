# BitChord for iPhone (proof of concept)

One screen: search YouTube Music, tap a song, and it plays through AVPlayer, in
the background too. It exists to prove the pipeline on iOS before porting more
of the phone app.

- `iosKit/` is the Kotlin side: a small anonymous YouTube Music client
  (WEB_REMIX search, IOS-client streams, which come unciphered), the AVPlayer
  wrapper and the Compose screen, linked as the static framework `BitChordKit`.
  It reuses `shared/commonMain`; nothing in `jvmSharedMain` runs on iOS.
- `iosApp/` is the SwiftUI shell that hosts that screen. Its Xcode project is
  generated by XcodeGen from `project.yml`.

## Getting it on a phone without a Mac

1. GitHub Actions runs the **iOS** workflow on every push to `ios/**` or
   `main` (or by hand from the Actions tab) and uploads
   `BitChord-unsigned-ipa`.
2. Unzip it and open `BitChord-unsigned.ipa` in Sideloadly or AltStore on
   Windows. They sign it with your Apple ID and install it. A free Apple ID's
   signature lasts 7 days.

## On a Mac

```bash
brew install xcodegen
cd iosApp && xcodegen generate && open BitChord.xcodeproj
```

Xcode's pre-build phase runs `./gradlew :iosKit:embedAndSignAppleFrameworkForXcode`,
so a plain Run builds the Kotlin too. The parser tests run anywhere:
`./gradlew :iosKit:jvmTest`.
